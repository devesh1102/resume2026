## Contributions & Impact

### Copilot V3 Integration

#### Copilot V3 Pipeline Integration
- Integrated the **Copilot V3 pipeline** into codebase.
- **Impact: Achieved overall efficiency of more than 75% on a regular basis.**
- Enables customers to guide Copilot in making queries related to specific fields using examples and instructions.

#### Example API Implementation
- Implemented CRUD APIs to enable users to register queries, which are then used in prompts by Copilot.
- Updated WAF policy to allow KQL written by customers to pass through the Application Gateway.
- Added a **List API** to enable users to add multiple examples at once.
- Added an API to retrieve all examples linked to an instruction.

#### Inbuilt Jobs
- Wrote an inbuilt **alias job** to register out-of-the-box aliases used in Copilot prompts for getting context and connecting queries with entities.
- Wrote an inbuilt **instruction job** to register inbuilt instructions (handles case where customer edits an existing instruction — it would not be updated).
- Wrote an inbuilt **examples job** to register inbuilt examples.

#### Job to Create Graph Functions (ADX)
- Developed a Graph function in ADX that abstracts graph creation using property and relationship tables.
- Integrated Shuffle strategy in the query to make computation faster.
- Registered these functions as startup jobs, utilized by Copilot in its queries.

#### Instruction Retrieval / Prompt Generation
- Wrote code to integrate examples, instructions, and alias dictionary into prompt.
- Added retries in the query API flow — previous errors are propagated in the next prompt for query generation.
- Optimized the flow by implementing **parallel calls** for data fetching from Cosmos.

#### Code for Converting KQL to Cipher Text
- Cipher-based queries are easier for Copilot to handle compared to KQL.
- Made code changes to internally convert example KQL provided by users to cipher-based KQL.
- **Impact: Customers can continue using their existing KQL without needing to learn new cipher-based queries.**

#### Added Typecast in Queries
- Investigation revealed Copilot often fails to add typecasting of columns in its queries, resulting in failing queries and reduced accuracy.
- Made code changes to apply typecasting on generated queries based on column type defined in the DTDL.

#### Fixing L2 Tests
- Registered custom examples and queries required to validate API L2 test to run on bakery dataset.

#### Removed V2 Implementation
- Removed obsolete V2 APIs from the codebase for better readability and code maintainability.

### GSI and Customer Engagement

#### OEE Query for Parsec
- Wrote **Overall Equipment Effectiveness (OEE) Query** for Parsec data that was mapped to our entities.

#### Fixing Deployment Failure for Schaeffler
- While being DRI, Schaeffler was facing deployment issues due to incorrect permissions at subscription level.
- Worked with Shubham to fix the issue.

### POC Work

#### Assistant API Spikes
- Created functions in ADX to **denormalize the entity structure** — view functions to be used by Assistant APIs for generating data for computation.
- Extended the Assistant API spike to include new views; wrote Python script to analyze accuracy of Assistant APIs with newly created views.
- Explored and demonstrated a working solution for **generating and updating graphs through the Assistant** based on results generated by Copilot.

#### Decomposition of Entity
- Copilot struggles when segregating an entity into multiple parts and applying filters.
- Tried decomposition of entity — making a new entity out of an existing entity just for Copilot calls.
- **Result: Achieved similar accuracy with 50% less instructions (6 out of 12) and only 3 examples (down from 8).**

### Bug Fixes
- **Added Previous Validation Error in Prompt:** Ensured previous validation errors that happened on last KQL generation are propagated in next run.
- **Added Fix for Intent Detection Skill:** Fixed issue where intent detection call result was adding additional text on moving to new version of OpenAI.
- **Fix Instruction ID:** Fixed mismatch in ID field stored in ADX vs fetched in code during retrieval.
- **Validate Doc Creation Failures:** Added await while validate doc creation call to properly fail the validate API call.
- **Responsible AI Testing:** Tested responsible AI and jail-breaking scenarios on the solution; contributed for testing the RAI Review — found vulnerabilities by disabling out-of-the-box examples and registering custom instruction with malicious content.
