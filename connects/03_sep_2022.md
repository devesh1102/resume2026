## Contributions & Impact

### Create Linked Service Flow
- Created API for creating linked service connection in Synapse.
- API supports creating storage-linked service connections and other linked connections (flexible payload).
- Made test connection for validation: makes a test call to Synapse to validate the payload — ensures no dysfunctional linked service is formed which would fail the ingestion pipeline.
- Wrote L1 test for this flow.

### Register Entity Flow
- Created API for creating a custom table in Synapse by the customer.
- API enables users to define relationships between tables.
- Validated payload, polled job to ensure registered entity creation in Synapse.
- Contributed to uploading out-of-box schemas in Cosmos.
- Wrote L1 test.
- **Impact:** Enables users to create custom entities/tables for storing data.

### AKS Deployment
- Worked with Suresh for Dogfood deployment.
- Wrote the **Dockerfile** for both IDS service and worker service.
- Wrote YML files to build Docker images in PR and official pipeline.
- Tested the image in an AKS cluster and fixed code for running in the cluster.

### Create Dataverse Linked Connection
- Explored how to connect to Dataverse from Synapse.
- Explored different authentication methods; settled on **User-Managed Identity**.
- Wrote logic to create Dataverse linked connection in Synapse.

### POC: Virtual Table and Data Virtualization
- Used virtual tables to import IDS data from Dedicated SQL Pool and Azure SQL Server into Dataverse.
- Compared **Custom Virtual Table Provider** vs **Inbuilt Virtual Table Provider** for CRUD operations.
- **Impact:** Solves problem of data duplication in Dataverse through data virtualization.

### POC: Incremental Copy in Synapse
- Created a pipeline in Synapse to incrementally copy data from two or more sources to a dedicated SQL.
- Optimized pipeline to copy only incremental data instead of the whole dataset.
- Displayed data from dedicated SQL to the Dataverse platform.
