## Contributions & Impact

### Coding Work

#### Unit Tests for Nov Private Preview (Oct 2022)
- Initiated initial projects for I0 for Nov private preview.
- Collaborated with Pragya to write tests for service as well as controller projects.
- **Impact:** Bolsters product quality and reduces bugs early on.

#### Register Inbuilt Entities Job (Jan 2023)
- Wrote startup jobs for registering inbuilt entities; creates MDS health doc to indicate whether startup jobs were successful.
- Wrote code for registering default entities to Azure Digital Twin by fetching DTDL models through URL in payload.
- Built a **Register Entities Payload Tool** for creating payloads for inbuilt entities — greatly reduced developer time to create payloads for ~80 entities and eliminated human error.

#### Create, Delete and Get API (Jan 2023)
- Added API for creating and deleting register entities — enables users to register custom entities and use schema to ingest data.
- Added Get API to fetch health doc status of MDS startup job and individual registered entity.
- Wrote unit tests for all functions and L1 test for the controller.

#### Making Ingestion Project Work in Azure Function (Feb 2023)
- Made changes in ingestion work in Azure Functions; made accurate Bicep changes for proper permissions.
- Migrated dependency from app settings to function app config.
- Updated codebase to read from function app config instead of appsettings.json.

#### Bicep (Feb 2023)
- Added and modified existing Bicep files for new resource creation.
- Streamlined different storage accounts used across the solution into three: background jobs, Azure functions, and batch ingestion.

#### Virtual Network and Private Endpoints (Feb 2023)
- Moved all resource-containing user data behind virtual network — **no outside connections can be made**.
- Made private DNS zones and private endpoints for all resources to communicate with each other.
- Divided the virtual network into subnets for different resource types.
- Made managed private endpoints to access resources from Azure Data Explorer.
- **Impact:** Greatly improved security of the solution.

### Technical Debt & Codebase Improvements

#### Remove Warnings (Mar 2023)
- Removed about **1,152 warnings** from the codebase (null exceptions and unnecessary async keyword usage).
- Configured projects to treat warnings as errors going forward.
- **Impact:** Improved code quality and decreased chance of null errors in future.

#### Standardize Exception Handling (Apr 2023)
- Standardized exception handling according to HTTPS standards — streamlines different exceptions to a common format with all relevant information.

#### L0 Coverage Check (Apr 2023)
- Added code coverage check in the Azure pipeline; automatically fails PRs if L0 coverage is below 70%.
- **Impact:** Ensures every line of code pushed is of great quality.

### POC Work

#### Function App (Nov 2022)
- Got familiar with Azure Function working; explored different triggers.
- Used Cosmos trigger of the function app to read data from Cosmos and write to Event Hub.

#### Azure Data Explorer and Continuous Export (Dec 2022)
- Collaborated with Shubham to explore continuous export feature of Azure Data Explorer to transfer cold data.
- **Impact:** Could save customer money as storing in ADX is expensive. Feature later implemented in the solution.

#### Alternate Approach to Mimic Hops (Apr 2023)
- POC to mimic hops in Azure Data Explorer (vs Azure Digital Twin).
- Tested performance of queries on data stored in both ADX and cold data (ADLS).
- **Results: ADX was 5–6x faster.** Wrote one-pager about findings.
