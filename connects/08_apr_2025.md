## Contributions & Impact

### Copilot Assistant Implementation (MDS)
- Proactively explored Azure OpenAI's assistant features through POCs; collaborated with Ashutosh (PM) to strategically devise implementation plan targeting completion before **April 2025 for HMI 2025 showcase**.
- Implemented a **filtering layer** between manufacturing plant datasets and the assistant — queries and extracts relevant data subsets before sending to assistant, drastically reducing computational load and improving efficiency.
- Implemented **conversation IDs** to enable users to ask follow-up questions seamlessly, building upon previous exchanges.
- With assistant API integration, users can now **generate charts directly** and leverage advanced reasoning capabilities — not available in previous V3 pipeline.
- **Assistant achieved accuracy rate exceeding 75% on the bakery dataset.**
- Wrote L0 and L2 tests specifically for the assistant.
- **Successfully showcased the Copilot Assistant implementation at a wide MCI audience — first onboarding of an assistant feature for any team across MCI.**
- **This assistant feature was leveraged during Customer Engagements and powered the Rolls Royce HMI demonstration.**

#### Upgrading Copilot Assistant Library
- Upgraded to the latest `Azure.AI.OpenAI.Assistant` library.
- Made modifications to handle breaking changes in the new version.
- New features enabled: **File search** and **attaching files at thread level**.

#### Adding File Search Capability in Assistant
- Added file search capability in assistant APIs.
- Users can add user-specific information to the assistant; the Assistant performs similarity search with the query and takes the most relevant file information for computation.

#### Modify Base Prompt For Assistant
- Implemented APIs to facilitate the direct addition of user-defined instructions to the assistant's base prompt — enabling more personalized responses.
- Developed CRUD API endpoints to allow users to manage and modify previously configured instructions.

#### Views Creation
- Created 5 different views for the assistant to query:
  - **Downtime View:** Retrieves data containing downtime information
  - **Actual Production View:** Retrieves actual production data
  - **Actual Consumption View:** Retrieves actual consumption data
  - **Scheduled Production View:** Retrieves scheduled production data
  - **Scheduled Consumption View:** Retrieves scheduled consumption data
- Views made data fetching easy — most complex traversal logic handled by the query itself. Made use of **materialized views of ADX** to make queries faster.

#### Wrote Validate Assistant Job
- Wrote assistant validate job — users can test if the assistant's answer is correct or not.
- Automatically gives a consolidated score on how well Copilot answer was.
