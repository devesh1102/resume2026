## Contributions & Impact

### Coding Work

#### Removing Azure Digital Twin (Nov 2023 – Dec 2023)
- Modified ingestion architecture to remove Azure Digital Twin — **greatly helped in scaling ingestion flow** to handle larger ingestion rates and **reduced cost** (ADT was most cost-heavy resource).
- Modified all flows to use direct ingestion in ADX:
  - Node creation
  - Relationship creation
  - OPCUa data creation
- Modified the GROUP BY clause to process multiple twins in a single call to ADX — **eliminated a major bottleneck** for relationship ingestion.
- Implemented Bicep changes for the update entity flow to enable direct ingestion in Azure Data Explorer.
- Optimized ingestion host and Function App configuration settings for optimal performance.
- **Impact: Reduced ingestion time from 18 minutes → 11 minutes for 330k nodes. Improved relationship ingestion time from 39 minutes → 18 minutes.**

#### Vectorization in Ingestion Flow (Jan 2024)
- **Ingestion Flow:**
  - Revised ingestion flow to perform **vectorization of selected entities concurrently** with ingestion (previously handled by a background job of Copilot service).
  - Leveraged Redis to store metadata for schema and relationship vectorization, increasing throughput.
  - Implemented retry mechanism for Copilot calls to manage throttling issues.
- **DMM Service:**
  - Introduced an API to modify the `isProperNoun` fields for columns in both inbuilt and custom entities.
  - This field allows customers to vectorize certain columns, enhancing the performance of Copilot.
- **Inbuilt Job:** Configured the inbuilt job to generate the necessary mappings and tables for vectorization.
- Implemented Bicep changes to enable Function App to access **Azure OpenAI through Managed Identity**.
- Decoupled the vectorization flow entirely to prevent interference with the regular ingestion flow — introduced a dedicated Event Hub solely for vectorization.

#### Logging Improvement (Jan 2024)
- Improved logging within the ingestion flow by eliminating excessive and redundant logs.
- Introduced logs within the ingestion flow for critical pathways.

#### Migration to dotnet8 (Feb 2024)
- Migrated codebase including SKG, Copilot, and ingestion from **dotnet 7 to dotnet 8** — enables enhanced security and compliance.
- Made relevant Bicep changes so that Function App and AKS pods are also updated.
